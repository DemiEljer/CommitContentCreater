Описание аргументов:
==========================================
-g [path]         : Сгенерировать файл истории из лога git (по умолчанию - \"log.txt\");
-v                : Вывести текущую версию проекта;
-h                : Выводит справочную ифнормацию по утилите;
-c                : Флаг очистка проекта от строк с описанием коммита;
-e [extention]    : Указание допустимое расширения файла для поиска описания коммита (-e h -e c);
-f [path]         : Указание конкретного файла для анализа;
-u                : Обновить утилиту (не используется);
-t                : Показать обнаруженные файлы;
<Path>            : Путь к директории указывается просто как строка.
==========================================
Нотация конфигурационного файла (commit.gen):
==========================================
extentions: [extention1], [extention2], ... ;    : Указание допустимых расширений файлов для поиска описания коммита (-e h -e c);
files: [path1], [path2], ... ;                   : Указание конкретных файлов для анализа;
project: [path];                                 : Путь к директории указывается просто как строка;
clear;                                           : Флаг очистка проекта от строк с описанием коммита;
tracing;                                         : Вывести все обнаруженные файлы.
==========================================
Аспекты нотации оформления строк описания коммита в тексте программы:
==========================================
//~ [Comment]     : Строка комментария коммита (одиночная);
/*~ [Comments] */ : Строка комментария коммита (многосточная);
//~ va.b.c        : Указание дельты новой версии (//~ v0.0.1 : v1.0.0 -> v1.0.1);
-[-][-]...        : Управление табуляцией (вложенностью);
//~~~			  : Экранирование фрагментов кода от поиска коммитов.
Сокращения и модификаторы:
#!                : Комментарий-заголовок (без -);
#[Number]         : Позиция комментария в коммите;;
#f                : [FIX];
#m                : [MODIFY];
#e                : [EVENT];
#u                : [UPDATE];
#a                : [ADD];
#i                : [INFORMATION];
#n                : [NOTE];
#c                : [CORRECTION];
#im               : [IMPROVEMENT];
#rm               : [REMOVE];
#rp               : [REPLACE];
#ph               : [PLACEHOLDER];
#ex				  : [EXTENTION];
#uc               : [UNCHECKED].
