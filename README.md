## CommitContentCreater
Утилита для генерации тела коммита на основе информации, указанной в коде, с помощью специальной разметки. Также, она позволяет вести файл историчности, согласуя номера версий.

### Пример верстки в коде

```C
//~ - Одиночная строка

// Данная нотация позволяет задать модификацию номера версии
// Последняя версия из файла "history.txt" будет изменена на указанные значения в каждой части версии (v1.0.0 -> v1.0.1) 

//~ v0.0.1

/*~
    - Многоcтрочный комментарий
    -- С указанием вложенности
    -- Второго уровня
    --- Каждый дефис добавляет один уровень вложенности
    --- С помощью табуляции
*/
```

### Аргументы утилиты

-g [path]        : Сгенерировать файл истории из лога git (...> git log > log.txt; по умолчанию - "log.txt");

-gx              : Сгенерировать файл истории в формате xml из файла историчности (history.txt);

-h               : Выводит справочную информацию по утилите;

-v               : Вывести текущую версию проекта;

-c               : Флаг очистка проекта от строк с описанием коммита;

-e [extention]   : Указание допустимого расширения файла для поиска коммита (-e h -e c);

-f [path]        : Указание конкретного файла для анализа;

-u			     : Обновить утилиту (не используется);

-t               : Показать обнаруженные файлы;

Path             : Путь к директории указывается просто как строка.

### Пример
``` CommitContentCreater.exe -c -e h -e c D:\Projects\TMS\Multiplex_Lipgart\MUX_Master_STM_Electro_52LV ```

### Использование файла конфигурации

При запуске утилиты, если не было передано ни одного аргумента, будет осуществлен поиск файла конфигурации в директории вызова утилиты с именем "commit.gen".

#### Данный файл имеет следующую нотацию заполнения:

```
    # Таким образом задаются комментарии #
    extentions: [extention1], [extention2], ... ;    # : Указание допустимых расширений файлов для поиска описания коммита (-e h -e c);"); #
    files: [path1], [path2], ... ;                   # : Указание конкретных файлов для анализа; #
    project: [path];                                 # : Путь к директории указывается просто как строка; #
    clear;                                           # : Флаг очистка проекта от строк с описанием коммита; #
    tracing;                                         # : Вывести все обнаруженные файлы. #
```

#### Пример

```  
    # Указание пути к проекту #
    project: . ;

    # Расширения файлов, в которых осуществляется поиск строк описания коммита #
    extentions: cs;

    # Отдельные файлы, в которых осуществляется поиск строк описания коммита #
    files: ;

    # Директива к удалению строк коммита #
    clear;

    # Директива к выводу найденных файлов #
    tracing;
```

### Используемые сокращения и специальные символы

Добавлена возможность сокращенной записи ключевых слов.

```
    #f,  #F  -> [FIX]
    #m,  #M  -> [MODIFY]
    #e,  #E  -> [EVENT]
    #u,  #U  -> [UPDATE]
    #a,  #A  -> [ADD]
    #i,  #I  -> [INFORMATION]
    #n,  #N  -> [NOTE]
    #c,  #C  -> [CORRECTION]
    #im, #IM -> [IMPROVEMENT]
    #rm, #RM -> [REMOVE]
    #rp, #RP -> [REPLACE]
    #ph, #PH -> [PLACEHOLDER]
    #uc, #UC -> [UNCHECKED]
    #ex, #EX -> [EXTENTION]
```
#### Пример

```C
//~ - #E Результаты командировки
//~ - #F Исправлено поведение дворников в случае возникновения ситуации рассинхронизации
```

#### Результат

```
- [EVENT] Результаты командировки
- [FIX] Исправлено поведение дворников в случае возникновения ситуации рассинхронизации
```

Реализована возможность создания строк заголовков, к которым не применяется алгоритм выравнивания вложенности

```
    #!
```

Поддерживается возможность задания позиции строки коммита

```
    // #[Number]
    #1 Первая строка
    #2 Вторая строка
    #3 Третья строка
```

### Результат (commit.txt)

```
v 1.0.1

- Одиночная строка
- Многострочный комментарий
    - С указанием вложенности
    - Второго уровня
        - Каждый дефис добавляет один уровень вложенности
        - С помощью табуляции
```

### Экранирование фрагментов кода

В случае, если фрагменты файлов необходимо исключить из поиска строк описания коммита, можно использовать блоки кода, помеченные "//~~~".

#### Пример

```

//~~~

    Данные строки не будут участвовать в поиске кода

//~~~

```

### Примечания
Используется утилита [UniversalUpdater](https://github.com/DemiEljer/UniversalUpdater/releases/tag/v1.0.0) для автоматического обновления.
